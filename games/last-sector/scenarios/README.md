# Last Sector Scenario Packs

Scenario packs are deterministic authoring/runtime fixtures used for QA, tutorial, tournaments and demos.

Each scenario may define:
- `boardLayout.cells`
- `playerSpawns`
- per-unit overrides
- `victoryMode`
- `victoryScore`

Current packs:
- `demo-party` — scripted end-to-end demo: move → resource → combat → return → victory.
- `combat-demo` — close-range combat fixture.
- `discovery-demo` — hidden-information and discovery fixture.
